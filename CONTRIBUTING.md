# Contributing to OrbitGrasp

Thank you for your interest in contributing!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes to `index.html` or `team-dashboard.html`
4. Test in your browser
5. Submit a Pull Request

## Development

The app is a **single HTML file** — no build step required.

```bash
# Run locally
python -m http.server 8080
# Then open http://localhost:8080
```

## Reporting Issues

Open an issue at [github.com/avanishkasar/OrbitGrasp/issues](https://github.com/avanishkasar/OrbitGrasp/issues)
