# OrbitGrasp Privacy Policy

OrbitGrasp is a **client-side only** application.

## Data Collection

- **Zero data collection** — We do not collect, store, or transmit any personal data
- **No analytics** — No tracking scripts of any kind
- **No accounts** — No sign-up required

## GitHub Tokens

- Stored exclusively in your browser's `localStorage`
- Never sent to any server other than `api.github.com`
- Cleared when you clear your browser data

## Repository Data

- All analysis is performed in your browser
- No repository content is transmitted to any third-party server

## Contact

For privacy concerns, open an issue at [github.com/avanishkasar/OrbitGrasp](https://github.com/avanishkasar/OrbitGrasp)
