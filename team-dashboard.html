🚀 Getting Started
Add a repoPaste owner/repo or a GitLab repository URL, press Enter or click + Add Repo.
WorkspacesOrganize different project groups into workspaces, saved automatically in localStorage.
Open in visualizerClick any repository name to deep-dive into its interactive dependency graph.
Re-analyzeTrigger a fresh client-side GitLab API analysis to update scores, issues, and CI/CD job statuses.
🔒 Privacy & Security
100% Client-SideAll computations and API calls happen directly in your browser. No background telemetry.
Direct QueriesRequests are sent directly to gitlab.com or your self-hosted GitLab instance.
Token StorageTokens are stored strictly in your browser's localStorage and never transmitted elsewhere.
